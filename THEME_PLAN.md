# Solo Leveling Theme Plan for Math Missions

## Theme Mapping

| Original Concept | Solo Leveling Equivalent |
|-----------------|-------------------------|
| Student | Hunter |
| Mission | Dungeon Gate / Raid |
| Materials | Hunter Equipment |
| Learning Targets | Skills to Unlock |
| Lesson Videos | Training Scrolls |
| Activity | Dungeon Raid |
| Parent Check | Guild Master Verification |
| Submission | Quest Completion |
| Progress | Level Up / XP |

## Visual Design System

### Color Palette
- **Primary Background**: #0a0a0f (Deep black/purple)
- **Secondary Background**: #1a1a2e (Dark purple)
- **Accent Blue**: #4cc9f0 (System notification blue)
- **Accent Purple**: #7b2cbf (Mana/magic purple)
- **Accent Gold**: #ffd700 (Legendary/rare items)
- **Text Primary**: #e0e0e0 (Light gray)
- **Text Secondary**: #a0a0a0 (Muted gray)
- **Success Green**: #00ff88 (Quest complete)
- **Warning Red**: #ff4444 (Danger/important)

### Typography
- Headers: Bold, glowing effect
- Body: Clean, readable
- System Messages: Monospace, bordered

### UI Elements
- Gate portals for mission cards
- XP progress bars
- Rank badges (E → S)
- "System" notification boxes
- Glowing borders and shadows
- Particle effects (CSS)

## Section Structure (Per Mission)

1. **[SYSTEM] DUNGEON GATE DETECTED** - Mission intro
2. **⚔️ HUNTER EQUIPMENT** - Materials needed
3. **📜 SKILLS TO UNLOCK** - Learning targets (unchanged)
4. **🎓 TRAINING SCROLLS** - Video lessons
5. **🏰 DUNGEON RAID** - Activity instructions (unchanged content, enhanced explanation)
6. **💡 RAID STRATEGY** - Step-by-step guide
7. **👑 GUILD MASTER VERIFICATION** - Parent checklist
8. **✅ QUEST COMPLETION** - Submission
