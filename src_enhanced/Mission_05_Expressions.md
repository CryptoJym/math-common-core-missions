## 📖 The Hunter's Knowledge (Brain Download)

### What is an Expression?

An **expression** is a mathematical phrase that combines numbers, variables, and operations:
```
Examples:
• 5 + 3         (just numbers)
• x + 7         (variable and number)
• 2a + 4b + c   (multiple variables with coefficients)
```

### Variables: Letters as Placeholders

When we don't know a number yet, we use a letter:
```
Let A = price of a sandwich
Let B = price of a drink

If A = $5 and B = $2:
A + B = $5 + $2 = $7
```

### Coefficients: Numbers in Front of Variables

When you see `2A`, it means "2 times A":
```
2A + 3B means:
(2 × A) + (3 × B)

If A = $4 and B = $2:
2A + 3B = (2 × $4) + (3 × $2) = $8 + $6 = $14
```

### Order of Operations (PEMDAS)

Always solve in this order:
1. **P**arentheses first
2. **E**xponents second
3. **M**ultiplication and **D**ivision (left to right)
4. **A**ddition and **S**ubtraction (left to right)
