## 📖 The Hunter's Knowledge (Brain Download)

### Adding Decimals

Line up the decimal points, then add:
```
  $0.45
+ $0.32
-------
  $0.77

Key: Keep decimals aligned!
```

### Subtracting Decimals

Same rule—line up the decimal points:
```
  $1.00
- $0.75
-------
  $0.25
```

### Multiplying Decimals

1. Multiply normally (ignore decimals)
2. Count total decimal places in both numbers
3. Put that many decimal places in answer

```
0.12 × 3 = 0.36

(12 × 3 = 36, then add 2 decimal places)
```

### Dividing Decimals

Move decimal to make divisor a whole number, then divide:
```
0.72 ÷ 0.08 = 72 ÷ 8 = 9
```

## 🗡️ The Quest (Activity)

### 📜 Verbatim Instructions:
Fluently add, subtract, multiply, and divide multi-digit decimals using the standard algorithm for each operation.

**Make a Buck:** Object of this game is to be the first person to collect ten cards that exactly equal $1.00. Play with a complete deck of cards:
- Ace = $0.01
- Two = $0.02
- Three = $0.03
- Four = $0.04
- Five = $0.05
- Six = $0.06
- Seven = $0.07
- Eight = $0.08
- Nine = $0.09
- Ten = $0.10
- Jack = $0.11
- Queen = $0.12
- King = $0.13

Shuffle the cards and deal ten cards to each player. Players then take turns drawing and discarding one card at a time until the deck of cards is depleted or a player collects exactly $1.00. This means it will involve a bit of logic and problem solving to discern which cards to keep and which to discard. The first player to collect cards that equal $1.00 wins that round and earns 1 point. If no one has $1.00 after the deck is depleted, the person closest to $1.00 without going over earns .5 of a point. The player with the most points at the end of ten rounds wins!

**How to Play:**

**Setup:**
1. Shuffle the deck
2. Deal 10 cards to each player
3. Place remaining cards face-down as draw pile

**Gameplay:**
1. Draw 1 card from the pile
2. Decide: Keep it or discard it?
3. Discard 1 card face-up
4. Next player's turn

**Winning:**
- First to reach EXACTLY $1.00 wins the round (1 point)
- If deck runs out, closest to $1.00 without going over gets 0.5 points
- Play 10 rounds. Most points wins!

**Strategy Example:**
```
Your hand: K, Q, J, 10, 9, 8, 7, 6, 5, 4

Total: $0.13 + $0.12 + $0.11 + $0.10 + $0.09
     + $0.08 + $0.07 + $0.06 + $0.05 + $0.04
     = $0.85

You need: $1.00 - $0.85 = $0.15 more

Strategy: Discard a low card, try to get higher!
```
